# Retailer Onboarding & KYC Flow (Very Important)

This is where trust is built.

## 🧾 Step-by-Step KYC Flow

**Step 1: Basic Details**
- Business name
- Owner name
- Phone & email
- Store address (GPS auto-detect)

**Step 2: Business Type**
- Kirana / Supermarket / Pharmacy / Other
- Delivery preference:
  - Self
  - Platform
  - Third-party

**Step 3: Document Upload**
- PAN card
- GST certificate (optional for small retailers)
- Bank details (cancelled cheque)

**Step 4: Verification**
- Auto-verify GST via API
- Manual review (admin)
- Status:
  - Pending
  - Approved
  - Rejected (with reason)

**Step 5: Go Live**
- Commission assigned
- Store visible to customers
- Test order enabled

## 🛡 Admin Controls
- Approve / reject retailers
- Set commission %
- Freeze payouts
- Audit logs
